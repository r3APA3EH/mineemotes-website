# mineemotes-website

Static landing page for Mine Emotes, built from the "сайт" page of the Figma design.

- `index.html`, `styles.css` — the page (no build step; open `index.html` or serve the folder, e.g. `npx http-server .`)
- `assets/` — SVGs exported from Figma

The emote preview image is loaded from `assets/preview.jpg` — add that file to show it in the preview tile and category cards.
